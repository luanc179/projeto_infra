# 🚀 Projeto de Infraestrutura, Containers e Observabilidade

Repositório criado para demonstrar competências práticas em administração de sistemas, conteinerização e monitoramento de ambientes corporativos.

---

## 🛠️ Tecnologias Utilizadas
* **Docker & Docker Compose:** Gerenciamento e isolamento de ambientes via containers.
* **Nginx:** Servidor web para simulação de aplicação de alta disponibilidade.
* **Grafana:** Painel de observabilidade e visualização de métricas em tempo real.
* **Git & GitHub:** Versionamento de código e documentação de portfólio.

---
